# Civic Pulse – Digital Governance & Public Information

Civic Pulse is a digital governance platform designed to connect citizens with public services and make civic issue reporting easier.

## Features

- Register civic complaints.
- Report issues such as road damage and garbage.
- Track submitted complaints.
- Access public information.
- View government schemes and announcements.

## Technology Stack

- Python
- Flask
- HTML
- CSS
- GitHub
- Render
